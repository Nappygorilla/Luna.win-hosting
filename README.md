# Luna.win Hosting

Marketing landing page for a Discord bot hosting service.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive black/white moonlight visual system
- `script.js` — mobile navigation and small UI behavior

## Deploy

This is a static site and can be published with GitHub Pages.

Before launch, replace the example plan prices and placeholder email/signup routes with your real hosting checkout and client-panel URLs.
