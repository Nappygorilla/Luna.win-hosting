ABOUT LUNA

Hosting built around the bot.

Luna.win is designed as a focused Discord bot hosting service: plan-based resources, authenticated service controls, persistent project data, and isolated runtime containers.

Service modelWebsite → Luna API → VPS agent → isolated bot container → Discord
Pre-launch statusPaid provisioning remains closed until infrastructure, billing, email, backups, quotas, monitoring, and operational controls are configured and tested.
